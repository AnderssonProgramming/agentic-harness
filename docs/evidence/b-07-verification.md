## Live run (Anthropic), `npm run verify:citations`

2 chat requests, model `claude-sonnet-5` (usage: 2,576 in / 402 out, 2,583 in / 199 out). Both replies went through the browser's own `parseSources` and `classifySources` (loaded with Vite's `ssrLoadModule`), against the list from `GET /api/knowledge`: `branch-naming.md`, `code-review.md`, `deploys.md`, `first-week.md`.

| Row     | Question                                                                   | Result                                                                                                                                                                |
| ------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| B-07 #1 | What is our branch naming convention?                                      | Pass. Last line `Sources: branch-naming.md` → `[{ branch-naming.md, known, "Branch naming" }]`, and `GET /api/knowledge/branch-naming.md` → 200, 728 chars. 4,005 ms. |
| B-07 #3 | Which state management library do we use for global state in the frontend? | Pass. "Our team documents don't cover this—none of the files I have (branch naming, code review, deploys, or first-week guide) mention…". No Sources line. 2,749 ms.  |
| B-07 #4 | (no model call) `GET /api/knowledge/..%2Fpackage.json`                     | Pass. 404.                                                                                                                                                            |

The "says so" check is a regex over the model's wording (`don't cover|not covered|…`). It's evidence that the prompt worked on this run, not a control. The control is that no Sources line means no chip, and a cited name that isn't loaded is visibly marked.
