# B-12 verification: "What's on my list?" answered from storage on every engine

Date: 2026-10-03. Delegation contract: `docs/delegations/b-12-list-from-storage.md`. Built by the `feature-builder` subagent.

## What changed

- **Browser** (`src/features/chat/hooks/use-chat.ts`): when the reply's `start` event says the engine can't run actions, each phrase the shared matcher (`todoPhraseActions`) finds in the user's message becomes a card, in order. A `list` phrase runs through the to-do feature's `execute`, which reads the stored list, so the card is the same `listed` card Claude's list produces. `add` and `complete` keep the `unsupported` refusal and never reach `execute`.
- **Server**: unchanged. `chat-core.ts` already sends only `start` and `done` for any to-do phrase on an engine without actions, so the model isn't called. New tests pin that down.
- **Not changed**: the protocol, the stored shapes (no snapshot version bump), Claude's path, and the mock with tools on.
