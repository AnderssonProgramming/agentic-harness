### What the first attempt ran into (no production impact)

1. **Gate:**
   - `npm ls` exited 1 on a clean install (an upstream peer range inside `netlify-cli`), and the gate couldn't read the result. Fixed in `6cbab8e`, which also fixed a deduped-subtree bug, then re-audited.
   - `npm ci` had first been blocked by leftover `vite preview` servers from verify runs and by a dev server holding Vite's native file.
2. **First draft (`6ac15c50007448e0a3e3ebb8`, never published):**
   - first got HTTP 401, from Netlify's visitor protection on non-production deploys. The PO turned it off;
   - then got the `config` error: the key was set for the Production context only. The PO added Deploy Previews and Branch deploys. A new draft was needed, because env vars apply only to deploys made after they're set.
